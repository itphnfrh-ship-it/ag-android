# ag-android

Приложение портовой администрации для проверки карт пассажиров и экипажа круизного лайнера.

Офицер передаёт код с карты. Приложение отправляет его в сервис ag-back и показывает, действительна ли карта, а также роль, имя, документ, судно и рейс.

Сканирование камерой — следующий шаг. Сейчас код вводится вручную, чтобы можно было проверить связку с сервисом.

## Запуск

Нужны Android Studio 2026.2 и запущенный ag-back. Адрес сервиса в отладочной сборке — `http://10.0.2.2:8080`: так эмулятор видит компьютер, на котором работает сервис. В отладке разрешён HTTP без TLS.

Демонстрационные коды карт описаны в README сервиса ag-back.

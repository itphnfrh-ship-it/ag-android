# CruisePass Verify

Приложение смотрит штрихкод карты пассажира или члена экипажа камерой или сканером и ищет код в локальной базе текущего круиза.

Если запись есть, показывается профиль. Если нет — предупреждение, что этого человека нет в текущем круизе.

При запуске приложение забирает список людей на борту и их фото с сервера 1С и сохраняет их на устройстве. Если сервер недоступен, остаётся последняя сохранённая копия. Поиск идёт по локальной базе. Кнопка в плашке круиза повторяет загрузку.

Язык интерфейса выбирается в шапке: английский, русский, турецкий, итальянский, греческий, египетский арабский.
